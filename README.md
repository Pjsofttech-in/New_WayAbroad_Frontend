# Wayabroad-style Next.js Homepage

## Install and run
npm install
npm run dev

Open: http://localhost:3000

Includes the full homepage based on the screenshots: navbar, hero, stats, university showcase, Why section, services, continent tabs, student essentials, consultation form, footer and WhatsApp button. Original website images are intentionally not included.


## SEO configuration

Set `NEXT_PUBLIC_SITE_URL` to the production website origin (for example, `https://your-real-domain.com`). The value is used by the Next.js metadata, robots and sitemap configuration. Do not leave a placeholder domain in production.
